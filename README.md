# Luizpicolo Apps

## How do I install these formulae?

`brew install luizpicolo/apps/thinkrails`

Or `brew tap luizpicolo/apps` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "luizpicolo/apps"
brew "thinkrails"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
